### `// FEATURED PROJECTS`

#### `[01]` CardioLink - Point-of-Care Cardiac Telemetry System
> *Supervised by Dr. Basant Kumar, Department of ECE, MNNIT Allahabad*
- **Hardware:** Built a multi-sensor health device on an ESP32-S3 interfacing an ADS1292R (ECG), MAX30105 (optical pulse and blood oxygen), and TMP117 (body temperature).
- **Signal Filtering:** Implemented digital filters in C++ to remove 50 Hz AC powerline hum and baseline drift from real-time ECG signals.
- **Telemetry:** Streamed live sensor data over USB-Serial to an interactive browser oscilloscope.

#### `[02]` Outside Plant (OSP) Fiber Optic Infrastructure
> *Engineering Trainee | IDOM Consulting, Engineering & Architecture (Riyadh, KSA)*
- Studied civil telecom routing, outdoor fiber deployment standards, and optical distribution network (ODN) layouts.
- Read manufacturer optical datasheets, calculated splice loss budgets, and drafted engineering review reports.

#### `[03]` Bharat-AI-SoC Touchless Gesture Interface
> *National Certificate - Arm & MeitY Student Challenge*
- Built a real-time hand gesture control system in Python running on an NVIDIA Jetson TX2 (ARM Cortex-A57).
- Tracked hand landmarks and mapped gestures to system commands with a 4-frame stability filter to eliminate false triggers.

#### `[04]` Pipelined Digital Filter Design on FPGA
> *Digital Design Lab @ MNNIT Allahabad*
- Implemented 4-tap FIR and Direct Form I IIR digital filters in Verilog HDL.
- Added pipeline registers to reduce critical path delay, increasing maximum clock speed from 159.8 MHz to 216.6 MHz in simulation.
- Synthesized and verified logic utilization on a Xilinx Artix-7 FPGA (Basys 3).

#### `[05]` ADAS - Advanced Driver Assistance System
> *Digital Image Processing Lab @ MNNIT Allahabad*
- Built a computer vision system in C++ using OpenCV for real-time lane detection and driver visual warnings.
- Used perspective transforms and edge thresholding to track road lanes under variable lighting.

#### `[06]` Embedded Robotics & Home Automation
> *BotRush 2.0 (Top 5 Finalist) & Avishkar Robotics @ MNNIT Allahabad*
- **Home Automation:** Multi-channel microcontroller relay controller with wireless switching and sensor feedback.
- **Robotics Bot:** Built long-range RF telemetry and motor drive circuits for an annual robotics competition ground bot.

#### `[07]` Low Dropout (LDO) Voltage Regulator
> *Analog Electronics & PCB Design*
- Simulated an analog LDO circuit in LTspice to verify loop stability and transient load response.
- Designed the physical 2-layer PCB layout and ran Design Rule Checks (DRC) in Altium Designer.
